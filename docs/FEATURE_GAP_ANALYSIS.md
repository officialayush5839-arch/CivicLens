# CivicLens Feature Gap Analysis: Baseline vs. Upgraded

| Capability Area | Baseline Capability (Smart Complaint) | Upgraded Capability (CivicLens) | Justification & Risk Mitigation |
| :--- | :--- | :--- | :--- |
| **Priority Classification** | Rigid substring matches; strips negation words destructively; completely ignores `category`. Bare priority string returned. | Multi-dimensional scoring (Safety, Disruption, Population, Time, Category); robust negation & contrast parsing; full `TriageResult` explainability report. | Eliminates false negatives on critical incidents; gives citizens and staff transparent reasoning. |
| **Priority Overrides** | None. Priority is immutable or directly manipulated without history. | Formal override workflow with mandatory rationale, actor logging, and original assessment retention in `priority_overrides`. | Promotes accountability; human-in-the-loop review protects against classification errors. |
| **Duplicate Detection** | None. Duplicate issues clog queues independently. | Offline TF-IDF & token overlap candidate detection; ranked similarity scoring; administrative incident grouping. | Prevents duplicate work; groups multi-victim outages into single incidents without losing individual records. |
| **SLA & Deadlines** | None. No target response or resolution times. | Configurable SLA policy matrix; real-time deadline computation; warning thresholds; idempotent escalation engine with startup reconciliation. | Prevents neglected cases; ensures transparent tracking of service level agreements. |
| **Complaint Lifecycle** | Loose status transitions (`SUBMITTED`, `ASSIGNED`, `IN_PROGRESS`, `RESOLVED`). Any employee can resolve without notes. | Validated `LifecycleStateMachine` with strict transition rules; mandatory resolution documentation; complainant appeals. | Prevents arbitrary or unverified status changes; ensures evidence-backed case closure. |
| **Audit History** | Zero event tracking. Only `updated_at` column in `complaints`. | Append-only `complaint_audit_log` recording actor, timestamp, event type, old/new states, and reasons. | Full legal traceability; non-repudiation for administrative actions. |
| **Complainant Feedback** | None. Once resolved, workflow terminates. | Citizen satisfaction rating (1-5), feedback notes, and authenticated appeal/reopen workflow. | Evaluates genuine resolution efficacy rather than mere closure speed. |
| **Privacy & Authorization** | Query errors expose DB structure; no row-level ownership checks; employee views expose all columns. | Role-based service guards; ownership validation on updates; PII separation; internal staff notes hidden from citizens. | Enforces data privacy and prevents horizontal privilege escalation. |
| **Configuration** | Hardcoded connection strings and passwords in `DbConnection.java`. | `AppConfig` supporting `.env`, `config.properties`, and environment variables with safe defaults. | Eliminates credential leakage in version control. |
| **Analytics & Reporting** | Simplistic counts and raw resolution percentage. | True SLA compliance %, median time to resolution, reopen rate, caseload balance, priority override frequency. | Provides actionable operational intelligence instead of misleading vanity metrics. |
| **UI/UX Design** | Default raw Swing layouts with inconsistent paddings and standard gray buttons. | FlatLaf modern desktop styling; clear hierarchy, color-coded badges, countdown timers, and accessible contrast. | Enhances operational ergonomics and user trust. |
